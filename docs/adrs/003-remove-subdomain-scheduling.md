# 003 Remove Subdomain Scheduling from Project Scope

* **Status:** Accepted
* **Date:** 2026-08-27

## Context and Problem Statement
The need was felt, to keep the core subdomains and corresponding use cases in a relatively small scope.

## Decision Outcome
The subdomain scheduling was removed from the defined project scope.

## Reasoning
* Focus on the other 3 related subdomains recipes, meal planning and inventory, which all revolve around food.

## Consequences
* **Positive:**
  * Faster workflows in future development by keeping related subdomains in scope and omitting the "off" one.
* **Negative:**
  * Missing on scheduling functionality in the app.
